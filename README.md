# GummyGram Localization

Client translations for GummyGram. Edit the JSON files in `values/langs/<language>/` directly; English is the reference language.

Keep translation keys and placeholders consistent across languages. Desktop strings are generated by `scripts/generate-desktop.py`; Android XML is generated by `scripts/generate-android.py`.

JellyPlugins documentation is maintained separately in the client repository in Russian and English.
